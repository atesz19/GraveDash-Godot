# Skeleton shop skins (KayKit)

- `Skeleton_{Minion,Rogue,Warrior,Mage}.fbx`
- `skeleton_texture.png` (FBX RelPath expects this next to the FBX)
- `texture/skeleton_texture.png` — duplicate for alternate RelPath

| ID | Name | Price |
|----|------|------:|

| skeleton_minion | Skeleton Minion | 10000 |
| skeleton_rogue | Skeleton Rogue | 20000 |
| skeleton_warrior | Skeleton Warrior | 25000 |
| skeleton_mage | Skeleton Mage | 30000 |
